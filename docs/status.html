Every A(DAI) Claude call is a 3-layer stack:
▪ relational-intelligence-protocol.md — always, the grammar of the system
▪ gatherer.md or reader.md — editorial engine (extract / interpret)
▪ adai-contribute · adai-view · adai-curate · adai-research — persona (conversation, tone, what practitioners see)
The gatherer is a tool, not a pipeline stage. You point it at a batch and say “go.” No event hooks, no automatic post-ingest trigger. processing_trace = NULL means “raw, unenriched” — a valid, expected state.
